# evritracking

Independent Next.js site for **SpeedPAK tracking** at [evritracking.com](https://evritracking.com) — EE/ES tracking numbers, eBay cross-border packages, and partner-network scans.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Multi-carrier tracking API integration

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Content

- Brand config: `src/lib/siteConfig.ts`
- Markdown pages: `src/content/`
- Blog routes: `src/app/<slug>/page.tsx`
- Public images: `public/` (logo, feature OG, blog covers)
